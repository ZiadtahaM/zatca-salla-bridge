# Architecture and Product Decision Records

This document records architectural decisions, context, rejected alternatives, and validation evidence for zatca-salla-bridge.

## Architectural Decision Matrix

| Identifier | Context and Problem Statement | Architectural Decision | Rejected Alternatives | Verification Evidence |
| :--- | :--- | :--- | :--- | :--- |
| ADR-001 | Unconditional unique constraint `uq_invoices_order_original` on `(egs_unit_id, order_id)` blocked replacement invoices when ZATCA reporting rejected an original document. | Applied Migration 004 to scope uniqueness to active records (`WHERE status NOT IN ('rejected', 'rejected_reporting') AND replaces_invoice_id IS NULL`). | Removing uniqueness altogether, which would risk race-condition duplicate invoices. | Live PostgreSQL test block successfully inserted a rejected invoice followed by a replacement invoice referencing it. |
| ADR-002 | Recovery routines fabricated synthetic orders with placeholder item names and artificial tax calculations when original payload was absent. | Enforce mandatory `raw_order_payload` persistence in PostgreSQL. Missing payload fails closed with `CANNOT_RETRY_WITHOUT_SOURCE_DATA`. | Preserving synthetic mock orders for test convenience, which would violate tax documentation integrity. | ZATCA Phase 2 guidelines mandate authentic supply details on every tax document. |
| ADR-003 | Remedying rejected simplified invoices without idempotency keys caused duplicate cancellation credit notes on network retry. | Derive deterministic idempotency key `${rejected.idempotency_key}:cancel_remedy` for credit note creation. Return existing credit note on retry. | Manual database cleanup by support engineers, which leaves inconsistent ledger states. | Automated tests confirm retry returns existing credit note without incrementing ICV counter. |
| ADR-004 | In-memory `Map` lock failed to serialize concurrent transaction workers in multi-instance or clustered environments. | Acquire PostgreSQL session-scoped transaction advisory locks (`pg_advisory_xact_lock`) per EGS unit during invoice generation. | External Redis distributed locks, which introduce extra operational infrastructure dependencies. | Monotonic counter benchmark confirms zero duplicate ICV values across concurrent transaction streams. |
| ADR-005 | Substring matching on raw XML misclassified mixed-basket invoices into incorrect VAT return boxes. | Parse signed XML DOM using `@xmldom/xmldom` to aggregate individual `<cac:TaxSubtotal>` elements into discrete return boxes. | Document-level category guessing, which corrupts multi-rate tax returns. | Form VAT 01 compliance verified against ZATCA UBL 2.1 schema specifications. |
| ADR-006 | Application booted with fallback development secrets when production environment variables were omitted. | Added startup environment validator throwing fatal errors if master encryption key, session secret, or webhook secret are missing in production. | Silent fallback to hardcoded development strings, which creates catastrophic credential exposure. | Server unit tests confirm production mode halts immediately when secrets contain default strings. |
| ADR-007 | Keyword matching on item names caused false-positive tax exemptions on physical merchandise containing words like voucher. | Require structured item classification (`is_voucher`, digital gift card types, or explicit zero-rate tax category). | Blind text substring searches across product titles. | Edge case tests confirm physical voucher accessories remain standard rated at 15 percent VAT. |
| ADR-008 | PostgreSQL blocks using newly added enum values within the same multi-statement query batch before commitment. | Separate migration statements into independent executions in `run-migrations.ts` and add enum values to initial schema scripts. | Shell script execution with psql CLI, which introduces external platform dependencies. | GitHub Actions CI run executed migration runner and passed all test suites on fresh PostgreSQL 16. |
